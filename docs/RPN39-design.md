# RPN39 —— RPN 计算器设计方案

> 状态：设计确认（2026-09-02），待开发。路线：阶段 1（4 层栈 + 四则）→ 阶段 2（科学）→ 阶段 3（简单函数绘图）。
> 定位：RPN 计算器（暂定名 RPN39）。高级功能（编程/矩阵/复数/统计/符号计算）**不做**——由 KhiCAS 实现。

## 一、机型基准：HP-42S 模式

| 项 | 42S | 35S | 结论 |
|----|-----|-----|------|
| 栈 | 4 层（X Y Z T + LAST X） | 8 层（显示 4 行需滚动） | **4 层**（与显示"4 行寄存器"吻合） |
| 菜单 | 软键菜单 | 不同风格 | **软键 F1-F6**（39GII 天然契合） |
| 按键 | 标准布局 | 布局差异大 | 39GII 物理键直接对齐 |
| 编程 | 有（裁剪不做） | 有 | 高级功能归 CAS |

实现**原创**（free42/Plus42 为 GPL-2.0 仅参考，禁止并入；wp43/MM-15 GPL-3.0 可参考）。

## 三、显示布局（320×240）

```
行1  T:  1234.5678          ← Hack 20px（等宽 14px）
行2  Z:  56.789
行3  Y:  789.0123
行4  123456.789             ← Hack 32px 大字（无前缀，结果行；输入中显示输入）
行5  ─ F1  F2  F3  F4  F5  F6 ─  ← 菜单行（12px，六段+竖线，黑底）
字体：Hack-Regular（OFL）经 tools/ttf2c.py 生成 HackAscii20/32；数字 ≤12 字符（超宽 %.6e 科学计数）

**显示精度约束（2026-09-02 定）**：固定 12 位有效数字，**不提供位数选择菜单**（硬编码）。定位：RPN39 = 数值快速计算（内部 double 15-16 位余量）；需要更高精度/符号计算（任意精度整数、精确分数、√2/π 保持）的用户使用 KhiCAS——两者互补，避免位数设置的复杂度和一致性维护成本。
```

- 标题行（顶部）显示应用名 + 角度单位状态（DEG/RAD，阶段 2 加）
- 4 行寄存器从上到下 T/Z/Y/X，X 在最下（HP 惯例）且大字体突出
- 输入中 X 行显示当前输入数字

## 四、菜单结构

默认菜单（F1-F6）：`x<>y | R↓ | DROP | (空) | (空) | 设置`

- 无物理键的 RPN 操作放菜单（x<>y/R↓/DROP）
- F6：设置（角度单位/显示位数等）——暂可留空
- MATH：数学功能菜单（阶段 2：三角/对数/幂根/概率/常量——翻页式）
- 有物理键的功能不进菜单（保持简洁）

## 五、存储（STO/RCL）

- 26 个字母寄存器（A-Z），STO 后直接按字母（自动 ALPHA 层解码——如 Vars=A、Math=B、SIN=E……）
- RCL 语义：值压入 X，栈上移（lift：X→Y→Z→T，T 复制）——与 ENTER 的"复制 X"不同
- **掉电持久化**：STO 变化时立即写文件（`/rpn39_sto.dat`，26 个 double ≈ 200B，写频低，NAND 磨损可忽略）

## 六、VARS 寄存器列表

- 按 VARS：列出 26 个寄存器（名称 + 数值），翻页浏览
- 选择 + ENTER = RCL（值压入 X，栈上移）
- 与 ( / ) 键的 RCL 等价（双路径）

### 阶段 2：科学计算（✅ 2026-09-03 完成，见 docs/RPN39-phase2-test.md）

**参考**：42S 行为基准；MM-15（15C）函数集有限参考；**WP43 仅参考不复刻**（功能过多）。

**函数语义约定**（RPN）：
- 单操作数 f(X)：X → f(X)（栈不动，lastX=旧 X，autoLift=1——算完可直接输下一数自动压栈）
- 双操作数 g(Y,X)：Y g X → X（栈下移，同四则）
- 常量（π/e）：`stackLift(); stX = 常量`（旧 X 上移——同 42S 常数输入，可连续输入参与运算）
- 角度模式（DEG/RAD/GRAD）作用于三角/反三角；标题行右侧显示 D/R/G

**实际键位映射**（39GII 物理键，依据原厂 shift 层）：

| 键 | 正常层 | Shift 层 |
|---|---|---|
| SIN / COS / TAN | sin / cos / tan | asin / acos / atan |
| LN | ln | e^x |
| LOG | log10 | 10^x |
| x² | X² | √X |
| x^y | Y^x（双操作数） | X 的 Y 次根（x^(1/y)） |
| ÷（运算键） | Y÷X | 1/X（倒数） |
| ×（运算键） | Y×X | X!（阶乘） |
| 3 | 3 | π（常量压栈） |
| ( / ) | STO / RCL（保留） | —（Shift+`(`=Copy、+`)`=Paste 原厂位不采用——STO/RCL 已占） |
| ABC（a b/c） | **小数/分数显示切换**（只影响 X 行显示） | STO/RCL 上下文 = C 寄存器（字母优先） |
| X,T,θ,N | **EEX 科学计数输入**（输入中追加 e+指数位） | STO/RCL 上下文 = d 寄存器；原厂 EEX 位于其 Shift 层，RPN39 直接放正常层（高频） |

**EEX 科学计数输入**（2026-09-02 规划+实现）：
- 正常层 X,T,θ,N = EEX：输入中追加 `e`（指数位）；非输入时先入 0 再追加
- CHS（±）在含 `e` 时作用于**指数区符号**（`1.5e-3` 再按 CHS → `1.5e3`）
- 输入长度限制 12 字符不变；atof 直接解析（内部 double 全精度，显示 12 位）

**a b/c 小数 ⇄ 分数显示切换**（2026-09-02 规划，仅 X）：
- **只切换 X 行的显示格式**（内部仍是 double，T/Z/Y 与运算不受影响）；再按切回小数
- 转换基于**显示值**而非二进制值：先 %.12g 舍入消除 double 噪声（0.1 → 精确 0.1）→ 连分数展开（终止阈值 1e-12×|v|）→ 最简分数显示（如 1.5 → `3/2`、1/3 → `1/3`）
- 转不出的值（√2、π 等）自动保持小数；分子/分母加位数上限防大整数溢出显示
- 压栈/计算产生新 X 后 fracMode 保持（新值同样尝试分数化）——升级路线：后续可扩展全行（T/Z/Y 独立尝试），本阶段仅 X

**MATH 菜单**（翻页式，F1-F6 每页 6 项；放无直接键位的功能）：
- 页 1 角度：DEG↔RAD↔GRAD 切换（含状态行刷新）
- 页 2 常量/基础：e、abs、sign、round、floor、ceil、frac
- 页 3 双曲：sinh cosh tanh asinh acosh atanh
- 页 4 概率/组合：nCr、nPr、RAND（0-1 随机）
- 页 5 幂/显示：x³、10^x、2^x、SCIENTIFIC 显示切换？（留）

（实现顺序：角度模式 → 直接键位函数 → Shift 层 → MATH 菜单；位深：函数先支持 X 实数）
