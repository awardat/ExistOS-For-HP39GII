# RPN39 —— RPN 计算器设计方案

> 状态：设计确认（2026-09-02），待开发。路线：阶段 1（4 层栈 + 四则）→ 阶段 2（科学）→ 阶段 3（简单函数绘图）。
> 定位：RPN 计算器（暂定名 RPN39）。高级功能（编程/矩阵/复数/统计/符号计算）**不做**——由 KhiCAS 实现。

## 一、机型基准：HP-42S 模式

| 项 | 42S | 35S | 结论 |
|----|-----|-----|------|
| 栈 | 4 层（X Y Z T + LAST X） | 8 层（显示 4 行需滚动） | **4 层**（与显示"4 行寄存器"吻合） |
| 菜单 | 软键菜单 | 不同风格 | **软键 F1-F6**（39GII 天然契合） |
| 按键 | 标准布局 | 布局差异大 | 39GII 物理键直接对齐 |
| 编程 | 有（裁剪不做） | 有 | 高级功能归 CAS |

实现**原创**（free42/Plus42 为 GPL-2.0 仅参考，禁止并入；wp43/MM-15 GPL-3.0 可参考）。

## 二、按键映射（原厂键位对齐）

### 物理键（直接可用）

| 键 | 功能 | 键 | 功能 |
|----|------|----|------|
| 0-9 . | 数字/小数 | (-) | CHS（正负号） |
| ENTER | 压栈（输入中=压栈；非输入中=复制 X 压栈） | + − × ÷ | 四则运算 |
| backspace | 输入退格 | Shift+backspace | CLx（清 X；原 Clear） |
| x² | 平方 | Shift+x² | √x |
| x^y | y^x | Shift+÷ | 1/x |
| SIN/COS/TAN | 三角 | Shift+同键 | ASIN/ACOS/ATAN |
| LN/LOG | 对数 | Shift+同键 | e^x / 10^x |
| Shift+3 | π | Shift+(-) | ABS |
| Shift+× | 阶乘 ! | | |

### 专用键

| 键 | 功能 | 说明 |
|----|------|------|
| **ON/C** | 取消/后退（短按）；Shift+ON/C 关机 | HP 原版 ON/C 语义（开机后为取消键） |
| **MATH** | 数学功能菜单（原厂语义） | 替代 F6 菜单 |
| **VARS** | 寄存器列表（26 个 A-Z：名称+数值） | 选择 + ENTER = RCL（值压入 X，栈上移） |
| **(** | STO（存数） | STO 后直接按字母（自动进入 ALPHA 层，无需按 ALPHA 键） |
| **)** | RCL（取数） | |
| VIEWS | 无定义（释放） | |
| F1-F6 | 菜单软键（下方菜单行） | F1 x<>y \| F2 R↓ \| F3 DROP \| F4/F5 空 \| F6 设置（暂） |

## 三、显示布局（320×240）

```
行1  T:  1234.5678          ← 小字右对齐
行2  Z:  56.789
行3  Y:  789.0123
行4  X:  123456.789         ← 大字（结果行；输入中显示输入）
行5  ─ F1  F2  F3  F4  F5  F6 ─  ← 菜单行（16px）
```

- 标题行（顶部）显示应用名 + 角度单位状态（DEG/RAD，阶段 2 加）
- 4 行寄存器从上到下 T/Z/Y/X，X 在最下（HP 惯例）且大字体突出
- 输入中 X 行显示当前输入数字

## 四、菜单结构

默认菜单（F1-F6）：`x<>y | R↓ | DROP | (空) | (空) | 设置`

- 无物理键的 RPN 操作放菜单（x<>y/R↓/DROP）
- F6：设置（角度单位/显示位数等）——暂可留空
- MATH：数学功能菜单（阶段 2：三角/对数/幂根/概率/常量——翻页式）
- 有物理键的功能不进菜单（保持简洁）

## 五、存储（STO/RCL）

- 26 个字母寄存器（A-Z），STO 后直接按字母（自动 ALPHA 层解码——如 Vars=A、Math=B、SIN=E……）
- RCL 语义：值压入 X，栈上移（lift：X→Y→Z→T，T 复制）——与 ENTER 的"复制 X"不同
- **掉电持久化**：STO 变化时立即写文件（`/rpn39_sto.dat`，26 个 double ≈ 200B，写频低，NAND 磨损可忽略）

## 六、VARS 寄存器列表

- 按 VARS：列出 26 个寄存器（名称 + 数值），翻页浏览
- 选择 + ENTER = RCL（值压入 X，栈上移）
- 与 ( / ) 键的 RCL 等价（双路径）

## 七、路线

### 阶段 1：RPN 核心
- 4 层栈（X Y Z T + LAST X）
- 四则 + ENTER/CHS/小数/退格/CLx
- 默认菜单框架（x<>y/R↓/DROP + 设置空位）
- 显示布局（4 行寄存器 + X 大字 + 菜单行）
- 集成：内置应用（System/applications/ 新建，Apps 页入口——App 方式不可行：System 无 .app 加载器）

### 阶段 2：科学计算
- 三角/对数/幂根/概率/常量（MATH 菜单 + Shift 层）
- 角度单位（DEG/RAD）状态显示

### 阶段 3：简单函数绘图
- y=f(x) 曲线绘制（大屏优势）
