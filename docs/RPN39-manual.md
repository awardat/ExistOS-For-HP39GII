# RPN39 用户手册

> RPN39 是 ExistOS 内置的 HP-42S 风格 RPN（逆波兰）计算器，适用于 HP 39GII（build 128+，当前 build 132）。
> 手册示例均为实测预期值；显示精度固定 12 位有效数字（更高精度请用 KhiCAS）。

---

## 1. 启动与退出

| 操作 | 效果 |
|---|---|
| Apps 页选中 **RPN39** 图标按 ENTER | 进入 RPN39 |
| **Shift + ON/C**（Shift 再按 ON/C） | 退出 RPN39 回 Apps 页（栈/寄存器/各功能数据自动保存） |
| 功能内（MATH 菜单/寄存器列表/复数/矩阵/统计）按 **ON/C** | 返回上级（菜单→主界面；矩阵/统计→主界面） |
| 主界面按 **ON/C** | 清除正在输入的内容（未输入时无动作，不退出） |

> ON/C 沿用 HP 原厂语义：开机后为**取消/后退**键。

---

## 2. 界面布局

```
RPN39           DEG          ← 标题行（右：角度模式；Shift 时显示 S）
T: 0            ← 原始值（第 4 层）
Z: 0            ← 第 3 层
Y: 0            ← 第 2 层
X: 0            ← 当前寄存器（大字，输入在此行进行）
x<>y | Rdn | DROP | Sum+ | Sum- | _   ← 底部软键菜单（F1-F6）
```

- 栈为 4 层：**X（当前值）/ Y / Z / T（最深）**。
- 输入时 X 行实时显示按键内容；Shift 激活后标题出现 **S** 指示，动作完成自动退出 Shift。

## 3. RPN 基本概念

RPN 不用等号和括号：先输入数字，再按运算符，运算作用于栈顶两层。

### 3.1 输数

按数字键直接输入（最多 12 位，含符号与小数点）。例：输入 `123.45` 按 `1 2 3 . 4 5`。

### 3.2 ENTER（压栈）

| 场景 | 行为 |
|---|---|
| 输入中按 ENTER | 把输入值压入栈（旧 X 移到 Y……），X 保持显示该值 |
| 非输入中按 ENTER | 复制当前 X 压栈（X 不变） |

### 3.3 自动提升（auto-lift）

**计算完成后输入下一个数字，X 自动压栈**（42S 语义）：

```
2 ENT 2 +     →  X=4
3             →  X 从 3 开始输入，旧值 4 自动移到 Y
```

### 3.4 四则运算

运算符作用于 **Y 与 X**：`Y op X → X`；Y 被消费，栈下移（Z→Y、T→Z）。

| 示例 | 按键 | 结果 |
|---|---|---|
| 5 + 3 | `5 ENT 3 +` | X=8 |
| 5 − 3 | `5 ENT 3 −` | X=2 |
| 5 × 3 | `5 ENT 3 ×` | X=15 |
| 5 ÷ 3 | `5 ENT 3 ÷` | X=1.66666666667 |
| 5 ÷ 0 | `5 ENT 0 ÷` | X=0（除零不崩溃，结果 0） |

> 复杂算式链：`(2×2)+(3×3)` → `2 ENT 2 × 3 ENT 3 × +` → X=13。

## 4. 栈操作（软键菜单 F1-F3）

| 键 | 功能 | 示例 |
|---|---|---|
| F1（x<>y） | 交换 X 与 Y | `1 ENT 2` 后 F1 → X=2, Y=1 |
| F2（Rdn） | 栈下滚（T→X 方向） | X/Y/Z/T 各下移一层 |
| F3（DROP） | 丢弃 X（Y→X，T 补 0） | 4 层栈 DROP 一次，T 变为 0 |
| F4（Sum+）/ F5（Sum−） | 统计收集/撤销（见第 13 章） | — |

> 任何栈操作前若正在输入，先自动收尾（输入值进入 X）再执行。

---

## 5. 输入与编辑

| 键 | 功能 |
|---|---|
| `.` | 小数点（每数一次） |
| `(-)` CHS | 正负号切换；输入含指数（EEX）时切换**指数区**符号（`1.5e-3` ↔ `1.5e3`） |
| X,T,θ,N（EEX） | 科学计数输入：追加 `e`（如 `1.5` 再按 EEX 输入 `3` → `1.5e3`） |
| 退格（←BS） | 输入中删末位；**非输入中从当前 X 进入编辑态**再删 |
| Shift + 退格 | CLx（清 X 为 0） |

显示规则：
- 整数 ≤ 11 位直接显示；更长自动转科学计数（`%.6e`）。
- 输入超长只保留前 12 字符可读。

## 6. 寄存器与变量（A-Z）

RPN39 提供 **26 个字母寄存器**（A-Z，存 double），掉电保留。

| 键 | 功能 | 示例 |
|---|---|---|
| `(`（STO） | 存入：按 `(` 后直接按字母键（自动进入字母层） | `123 STO A`：按 `1 2 3` 再按 `(` 再按 a 键 → A=123 |
| `)`（RCL） | 取出：按 `)` 后按字母 → 值压入 X（栈提升） | `RCL A` → X=123，原 X 移 Y |
| VARS | 寄存器列表（滚动查看全部 26 项） | 选中行按 ENTER = RCL 该寄存器 |
| Shift + ↑ / ↓ | 列表整页翻页（8 行/页） | — |
| Shift + 退格（列表内，按两次） | 清空全部寄存器（第一次确认，第二次执行；ON 取消） | — |

> 按 `(` 出现 `STO _`、按 `)` 出现 `RCL _` 提示；按键非常规字母键 = 取消等待。

### 6.1 STO 运算（42S 累加器）

`STO` 后按 **Shift + 四则键**，再按字母：寄存器 = 寄存器 **op** X。

| 操作 | 效果 |
|---|---|
| `STO A` 后 `Shift +` 再按 a | A = A + X |
| `STO A` 后 `Shift ×` 再按 a | A = A × X |
| `STO A` 后 `Shift ÷` 再按 a | A = A ÷ X（X=0 时保持 A 不变） |

> 例：A=100，输入 25 后 `STO Shift+ a` → A=125。

## 7. 科学函数（物理键）

### 7.1 正常层

| 键 | 功能 | 示例（DEG） |
|---|---|---|
| SIN / COS / TAN | 三角函数（按当前角度模式） | `90 SIN` → 1 |
| LN / LOG | 自然对数 / 常用对数 | `100 LOG` → 2 |
| x² | 平方 | `5 x²` → 25 |
| x^y | Y 的 X 次幂 | `2 ENT 5 x^y` → 32（Y=2, X=5） |
| a b/c | 小数 ↔ 分数显示切换（见第 9 章） | `1.5` 按 a b/c → `3/2` |

### 7.2 Shift 层（按 Shift 后按对应键，动作完成自动退 Shift）

| 键 | 功能 | 示例 |
|---|---|---|
| Shift + ÷ | 1/X | `4` → 0.25 |
| Shift + × | 阶乘 X! | `5` → 120 |
| Shift + x² | √X | `16` → 4 |
| Shift + x^y | Y 次根：X^(1/Y) | `8 ENT 3` → 2（8 的 3 次根） |
| Shift + SIN / COS / TAN | ASIN / ACOS / ATAN（结果按角度模式） | `0.5` → 30（DEG） |
| Shift + LN / LOG | e^x / 10^x | `1` → 2.71828182846 |
| Shift + 3 | π 压栈 | — |
| Shift + `(-)` | ABS（绝对值） | `-5` → 5 |
| Shift + 退格 | CLx | 清 X |

> 负数的奇次根支持：`-8 ENT 3` 按 Shift+x^y → -2。

## 8. 角度模式（DEG / RAD / GRAD）

- 切换：MATH 菜单第 1 页 F1/F2/F3（见第 10 章），或随时在 MATH 菜单内操作。
- 状态：主界面标题右上显示 **DEG / RAD / GRAD**。
- 三角/反三角按当前模式换算；持久化（重启保持）。
- 近零噪声舍去：`90 COS` 结果为 **0**（而非 6.1e-17）。

## 9. 分数显示（a b/c）

a b/c 键**仅切换 X 行的显示方式**（内部仍为 double，不参与计算）。

| 输入 | 按键 | X 行显示 |
|---|---|---|
| 1.5 | a b/c | `3/2` |
| 0.33333333333（12 位） | a b/c | `1/3` |
| 0.125 | a b/c | `1/8` |
| √2（1.4142135624） | a b/c | 保持小数（连分数转不出时自动回小数） |
| 123456789 | a b/c | 保持小数（超出范围） |

算法：按显示值进行连分数逼近（误差 1e-12），得到最简分数；转不出（π/√2 等）保持小数。再按一次 a b/c 切回小数。

> 输入中按 a b/c 先自动收尾（`1.5` 直接按 → 显示 3/2）。

## 10. MATH 菜单（数学功能）

按 **MATH** 键进入。5 页循环翻页（**左/右/上/下键翻页**，第 1 页向左 → 第 5 页），**数字键 1-5 直接跳页**；ON 退出。

| 页 | 标题 | F1 | F2 | F3 | F4 | F5 | F6 |
|---|---|---|---|---|---|---|---|
| 1 | 角度/ANGLE | DEG | RAD | GRAD | %（…%/百分） | Δ% | %T |
| 2 | 常量/BASIC | e | sign | round | floor | ceil | — |
| 3 | 双曲/HYPER | sinh | cosh | tanh | asinh | acosh | atanh |
| 4 | 概率/PROB | nCr | nPr | RAND | — | — | — |
| 5 | 幂/POWER | x³ | 10^x | 2^x | — | — | — |

### 10.1 页 1：角度切换 + 12C 百分比

| 项 | 说明 | 示例 |
|---|---|---|
| DEG / RAD / GRAD | 切换角度模式 | — |
| % | X = Y × X ÷ 100（**只改 X，Y 保持**——算完可直接 + 得合计价） | `200 ENT 25` 按 % → X=50；再按 `+` → **250**（含税价） |
| Δ% | X = (X − Y) ÷ Y × 100（相对变化） | `200 ENT 25` 按 Δ% → **-87.5**（25 相对 200 降 87.5%） |
| %T | X = X ÷ Y × 100（占比） | `200 ENT 25` 按 %T → **12.5**（25 占 200 的 12.5%） |

### 10.2 页 2：常量与取整

| 项 | 功能 | 示例 |
|---|---|---|
| e | 自然常数压栈（2.71828182846） | — |
| sign | 符号：正→1、负→-1、零→0 | `-5` → -1 |
| round | 四舍五入到整数 | `2.5` → 3 |
| floor | 向下取整 | `-2.5` → -3 |
| ceil | 向上取整 | `2.1` → 3 |

### 10.3 页 3：双曲函数

| 项 | 示例（X=1） | 结果 |
|---|---|---|
| sinh | 双曲正弦 | 1.17520119364 |
| cosh | 双曲余弦 | 1.54308063482 |
| tanh | 双曲正切 | 0.761594155956 |
| asinh | 反双曲正弦 | 0.88137358702 |
| acosh | 反双曲余弦（X≥1 有效） | 0（X=1） |
| atanh | 反双曲正切（|X|<1 有效） | 0.549306144334（X=0.5） |

### 10.4 页 4：概率

| 项 | 功能 | 示例 |
|---|---|---|
| nCr | 组合 C(Y, X) | `5 ENT 3` → **10** |
| nPr | 排列 P(Y, X) | `5 ENT 3` → **60** |
| RAND | 随机数 [0,1)（种子=时钟+X+计数器混合） | 每次不同序列 |

### 10.5 页 5：幂族

| 项 | 示例（X=2） |
|---|---|
| x³ | 8 |
| 10^x | 100 |
| 2^x | 4 |

## 11. 复数 CPLX（Shift + `,`）

按 **Shift + `,`**（键盘逗号键）进入。主栈 (Y, X) 与复数区之间的数据交换：**Y=实部、X=虚部**。

### 11.1 页面

| 页 | F1 | F2 | F3 | F4 | F5 | F6 |
|---|---|---|---|---|---|---|
| 1/3 | LOAD 0 | LOAD 1 | + | − | × | ÷ |
| 2/3 | CONJ | |Z0| | 1/Z0 | ARG | Z0→XY | R↔P |
| 3/3 | R>P | P>R | — | — | — | — |

（每次进入固定回页 1/3；`MATH/b` 键翻页循环；ON 退出）

### 11.2 基本用法

**载入与四则**（复数存两个槽 Z0、Z1，运算结果进 Z0）：

```
2 ENT 3  Shift+,  F1(LOAD 0)   →  Z0 = 2+3i
4 ENT 5  (回主界面) Shift+, F2(LOAD 1)  →  Z1 = 4+5i
F3(+)                                  →  Z0 = 6+8i
F4(−)                                  →  Z0 = -2-2i  （再用前面的值回验）
```

> LOAD 必须从**主界面**准备数据（复数页内数字键不参与输入）。

### 11.3 单位置函数（页 2/3）

| 项 | 功能 | 示例（Z0=3+4i） |
|---|---|---|
| CONJ | 共轭 | 3-4i |
| |Z0| | 模：√(a²+b²) 入 X | 5 |
| 1/Z0 | 倒数 | 0.12-0.16i |
| ARG | 辐角（按角度模式入 re） | 53.1301（DEG） |
| Z0→XY | 复数送回主栈（Y=实部 X=虚部） | 主界面 Y=3, X=4 |
| R↔P | 显示模式切换（RECT ↔ POLAR） | `5∠53.1301°` ↔ `3+4i`（标题右上指示） |

### 11.4 坐标转换（页 3/3，作用于主栈）

| 项 | 功能 | 示例（主界面 3 ENT 4 后） |
|---|---|---|
| R>P | 直角→极坐标：Y=模、X=辐角 | Y=5, X=53.1301（DEG） |
| P>R | 极坐标→直角（接上例） | 回 Y=3, X=4 |

- Z0/Z1 与显示模式（RECT/POLAR）**持久化**（/rpn39_cplx.dat），重启保留。

## 12. 矩阵 MATX（Shift + `4`）

按 **Shift + 4** 进入。三个矩阵槽 **A / B / R（结果）**，尺寸 1×1～4×4，格内值实时编辑。

### 12.1 页面与功能

| 页 | F1 | F2 | F3 | F4 | F5 | F6 |
|---|---|---|---|---|---|---|
| 1/3 | A+B | A-B | A*B | T(A) | T(B) | Ed:R |
| 2/3 | INV A | INV B | DET A | DET B | CLR R | Ed:A |
| 3/3 | SIZE | R->A | R->B | CLR A | CLR B | Ed:B |

（进入固定页 1/3；**MATH/b 键翻页**；F6 循环切编辑槽 A→B→R；ON 退出矩阵）

### 12.2 格编辑

- 方向键在格阵内导航（行尾自动换行：RIGHT 在行尾 → 下一行首格）。
- 数字、`.` 小数、`(-)` 负号、退格输入；ENTER 提交并前进一格。
- 正在编辑的格（黑底白字反显）切槽/翻页/退出时**自动提交**（值不丢）。
- 尺寸修改：页 3/3 F1(SIZE) 循环 1→4（修改同时清空该槽）。

### 12.3 运算示例

```
A=[[1,2],[3,4]]  B=[[5,6],[7,8]]

页3/3 F1(SIZE)×2 次  →  SIZE=2
输入 1 ENT 2 ENT 3 ENT 4            →  A
F6 切 B 槽，SIZE=2，输入 5 6 7 8    →  B
回页 1/3 F1(A+B)                    →  R=[[6,8],[10,12]]
F3(A*B)                            →  R=[[19,22],[43,50]]
页2/3 F3(DET A)                    →  X=-2（自动回主界面）
```

| 功能 | 预期 |
|---|---|
| det([[1,2],[3,4]]) | -2 |
| A⁻¹（INV A） | [[-2, 1], [1.5, -0.5]]（存 R） |
| T(A)（转置） | [[1,3],[2,4]]（存 R） |
| R->A / R->B | 把 R 拷回 A/B（链式复用） |
| CLR A/B/R | 清空该槽（尺寸回 1） |
| 奇异矩阵 INV（全 0） | 提示 **singular**，不崩溃 |

- 尺寸与矩阵数据**持久化**（/rpn39_matx.dat）。

## 13. 统计 STAT（Shift + `7`）

按 **Shift + 7** 进入；主界面也可直接按 **F4（Sum+）/ F5（Sum−）** 收集数据。

### 13.1 收集

```
10 F4  20 F4  30 F4  40 F4     →  4 个数据点（X 不被消耗）
```

### 13.2 统计页（8 项，↑↓ 选择，ENTER 取值回主栈）

| 项 | 示例值（10/20/30/40） |
|---|---|
| N（个数） | 4 |
| MEAN（均值） | 25 |
| POP sd（总体标准差） | 11.1803398875 |
| SMP sd（样本标准差） | 12.9099444874 |
| MIN / MAX | 10 / 40 |
| SUM（和） | 100 |
| SQ SUM（平方和） | 3000 |

| 键 | 功能 |
|---|---|
| ↑ / ↓ | 选择统计项（反显行） |
| ENTER | 选中项值 → 主栈 X（自动回主界面） |
| F1 / F2（底部菜单） | 继续 Σ+ 收集 / Σ− 撤销最后一点 |
| F3 | 清空数据 |
| ON | 退出统计（数据持久化） |

> Σ− 撤销的是最近一次收集（数据回退）。

### 13.3 持久化

数据点与选中项保存在 /rpn39_stat.dat，重启保留；退出时自动保存。

## 15. 常见问题

| 现象 | 说明 |
|---|---|
| 除零得 0 | 设计行为（RPN39 不报错，结果 0） |
| 矩阵 INV 提示 singular | 矩阵不可逆（行列式为 0），退出不崩溃 |
| ACOS/ATANH 无结果 | 超出定义域 |X|>1 返回 0 |
| 显示变科学计数 | 整数超 11 位或 |X|<1e-6 时自动 `%.6e` |
| 输入超过 12 位 | 超长部分不接收（输入框容量） |
| 统计页底部无菜单 | build 131 之前缺菜单条；132 已补（Sum+/Sum-/CLR） |
