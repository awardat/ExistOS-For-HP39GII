# KhiCAS 用户手册（HP39GII）

> 适用版本：**build 139**（giac 2.0.0 有限移植版）
> KhiCAS 是集成 giac/Xcas 计算机代数系统（CAS）的计算器环境：Console 交互计算、图形、脚本编辑器与 Python 兼容模式。
> 相关文档：[完整键位表](keymap.md) ｜ [Python 示例与约束清单](../samples/README.md) ｜ [运算速度说明](../README.md)

---

## 1. 启动与退出

| 操作 | 效果 |
|---|---|
| Apps 页选中 **KhiCAS** 图标按 ENTER | 进入 KhiCAS（自动恢复上次会话） |
| **Shift + ON/C** | 退出 KhiCAS 回 Apps 页（会话自动保存） |
| **HOME**（任意界面） | 回到 KhiCAS 初始界面（Console 根） |
| Console 内 **Shift + ENT** | 输入上次结果 Ans |

## 2. 界面布局

```
shell Xcas              ← 左上：当前语法模式（Xcas / Py ^=**）
...历史区...
Py>  1+1                ← 输入行（提示符反映语法模式）
     2                  ← 结果
```

- **图标行**（顶部）：shift / alpha / **沙漏**（计算中，>50ms 可见）/ 电池
- 长运算可切换**加速模式**提速约 2×（见 §8），慢的原因见 [运算速度说明](../README.md)

### 4.1 功能键与顶部区

| 物理键 | 功能 |
|---|---|

| **F4** / **MATH** | 命令目录（分类浏览 + 帮助） |
| **F5** | 日志（实验性，不落盘；导出请用 文件菜单 → 保存日志） |

| **SYMB** | 程序命令菜单（`:` `&` `#` `hexprint(` `f(x):=` `debug(` …） |

| 键 | 输入 | 键 | 输入 |
|---|---|---|---|
| Shift+2 | `i`（虚数单位） | Shift+3 | `π` |
| Shift+4 | 矩阵相关 | Shift+7 | 列表相关 |
| Shift+5 / 6 | `[` / `]` | Shift+8 / 9 | `{` / `}` |
| Shift+1 | 程序命令 | Shift+0 | **输入自动补全**（见 §7） |
| Shift+(-) | `abs(` | Shift++ | `∑` |
| Shift+− | `∠` | Shift+× | `!`（阶乘） |
| Shift+÷ | `1/x` | Shift+. | `=` |
| Shift+XTT | `×10ⁿ` | Shift+SIN/COS/TAN | `asin(` / `acos(` / `atan(` |

## 6. 变量

- **VARS 键** → 变量列表（标题 Variables）：↑↓ 选择、**ENT 插入变量名**、**DEL** 删除（purge）该变量
- 列表末尾另有：`purge(`、`assume(`、**`restart`**（清空全部变量，等价于新会话）
- 会话变量**退出/重启后仍保留**（会话恢复）；跑测试或换题目建议先执行 `restart`
- 删除单个变量：`purge(x)` 或 `purge(x,y)`

## 7. 输入自动补全（Shift+0）

在输入行输入前缀后按 **Shift+0**：

- 匹配范围：**355 条命令目录**（显示中文名）+ **1552 条内置函数名**
- **输入完整命令名**（如 `sin`、`sqrt`）→ 直接补全为 `sin(` / `sqrt(`
- 唯一匹配 → 直接补全为 `命令(`；程序结构（`while`/`if`/`for`）插入原文本
- 多匹配 → 弹出菜单选择（↑↓ + ENT）
- 无匹配 → 不动作；Python 模式过滤部分仅 Xcas 条目

示例：`integ`+Shift+0 → 菜单（integrate / integer_format / integrer）；`integra`+Shift+0 → 直接 `integrate(`；`sqr`+Shift+0 → 菜单（sqrt / sqrfree）。

## 9. 脚本编辑与运行

1. **准备**：`.py` 文件放到设备 `/xcas/` 目录（USB 磁盘模式复制）；文件用 **GBK 编码**（中文注释/字符串）
2. **打开**：文件菜单 → **打开脚本**（或按 **APPS** 键浏览）
3. **编辑**（编辑器）：
   - **F5 = 保存并运行**
   - **F6 = 编辑器菜单**：检查语法 / 保存 / 另存为 / 插入 / 清除 / 查找替换 / 跳转行 / Syntax / 字号 / 帮助 / 关于 / 返回
   - **检查语法**：Xcas 模式真正解析；Python 模式仅提示 Parse OK（不执行）
4. **运行**：编辑器 F5，或文件菜单 → **运行脚本**
5. **输出**：结果输出到 Console 主界面；导出用 **文件菜单 → 保存日志**（串口）
6. **计时**（KhiCAS 扩展）：
   - `time(表达式)` → 返回求值耗时（秒）
   - `time(1,2,3)` → 返回**毫秒时间戳**（用于脚本内计时）

> 示例脚本见仓库 `samples/`（01–06）：基础 / math / 列表 / 矩阵 / 绘图 / 蒙特卡洛。

## 10. Python 兼容模式

**切换**：Shift+Symb → 配置菜单 → 语法 → 「Xcas 兼容 Python」（左上显示 `shell Py ^=**`）。

### 10.1 命名约束（重要）

Python 兼容层由 giac 解析器实现，脚本标识符会与 **giac 内置名**冲突：

| 名称 | 原因 | 规避 |
|---|---|---|
| `i` | giac 虚数单位 | 循环/临时变量用 `k`、`j` |
| `e` | giac 自然常数 | 用 `ex`、`val` |
| `sign` / `sum` / `max` / `min` / `abs` / `floor` / `round` | giac 内置函数，不可重定义 | 自定义函数改名（`my_sign`…） |

### 10.2 其他限制

- **`True` 不可靠**：布尔值请用 `1` / `0`
- **复杂多分支循环体**（如 N-Queens 状态机）会卡死——兼容层解析限制；简单循环/单分支/嵌套均正常
- **多行 `def` 函数体**支持有限：建议单表达式函数或写成单行
- **括号跨行**不支持（逐行执行按物理行切分），保持单行完整
- **`caseval("...")`** 仅适合单行代码；多行代码返回空
- 注释行会被跳过（不执行）；中文必须 GBK

约束清单以 [samples/README.md](../samples/README.md) 为准（会持续更新）。

## 13. 常见问题（FAQ）

| 问题 | 说明 |
|---|---|
| 计算很慢（数秒~数十秒） | 符号算法固有开销（一次求值约 85ms）；切换**加速模式**约 2×；详见 [运算速度说明](../README.md) |
| 长计算期间按键无响应 | 计算同步占用 UI（顶部沙漏点亮）；结束后恢复。脚本死循环会一直卡住 |
| 脚本运行后卡死 | ON+F5 强制重启；检查是否用了复杂多分支循环体（§10.2） |
| 主界面 F5 日志空白 | F5 落盘路径不可用（已知）；请用 **文件菜单 → 保存日志**（串口导出） |
| π / 根号显示为空白或错位 | 在**数学排版视图**（结果行按 ←）查看；Console 文本视图已同步修复 |
| 对比度异常（无电池时） | 充电开关会抬升显示偏压；先关闭充电开关再调对比度（系统 ON+±） |
| 变量干扰结果 | 会话恢复会带回旧变量：先 `restart` 或 `purge(x)` |
